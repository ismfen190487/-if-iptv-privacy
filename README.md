 # Política de Privacidade - IF IPTV

  Última atualização: 27 de maio de 2026

  O aplicativo IF IPTV respeita a privacidade dos usuários.

  ## Coleta de dados

  O IF IPTV não coleta, armazena, compartilha ou vende dados pessoais dos usuários.

  O aplicativo não solicita cadastro, login, e-mail, telefone, localização ou qualquer outra informação pessoal.

  ## Conteúdo do usuário

  O IF IPTV é um aplicativo reprodutor de mídia. O aplicativo não fornece, hospeda, distribui ou vende canais, filmes, séries, listas IPTV ou
  qualquer outro conteúdo audiovisual.

  O usuário é responsável por utilizar apenas conteúdos, listas ou links próprios, autorizados ou legalmente permitidos.

  ## Permissões do aplicativo

  O aplicativo pode utilizar permissões técnicas necessárias para o funcionamento do reprodutor de mídia, como acesso à internet para carregar
  conteúdos informados pelo próprio usuário.

  Essas permissões não são usadas para coletar dados pessoais.

  ## Compartilhamento de dados

  Como o IF IPTV não coleta dados pessoais, nenhum dado pessoal é compartilhado com terceiros.

  ## Segurança

  Como o aplicativo não coleta dados pessoais, não há armazenamento de informações pessoais em servidores próprios do IF IPTV.

  ## Alterações nesta política

  Esta Política de Privacidade pode ser atualizada periodicamente. Quando houver alterações, a nova versão será publicada nesta mesma página.
